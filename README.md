# Random Password Generator

A simple Python password generator that creates secure random passwords based on user preferences.

## Features
- Generate multiple passwords.
- Customize password length (3–50 characters).
- Include uppercase letters, numbers, and symbols.
- Input validation.
- Secure randomness using `secrets`.

## How to Run

```bash
python main.py
```

## Built With
- Python
- `secrets`
- `random`

No external libraries required.
